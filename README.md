# Arabic Bahá’í Prayers website

Static Arabic RTL landing website for the mobile app.

## Local preview

From this folder:

```bash
python3 -m http.server 8080
```

Then open:

`http://localhost:8080`

## Important

- The six app screenshots are the user's original screenshots, used without recreating or altering their content.
- The original logo is used as supplied.
- Website typography uses Almarai, Aref Ruqaa, Changa, and Noto Sans Arabic.
- Review the privacy policy against final Google Play and App Store disclosures before public launch.
